I built a basic slot machine game with JavaScript inspired by my love of Philly Sports by first creating a display with three slots that show the 5 different Philly Sports team's logo when you spin. When the player presses the spin button, the JavaScript randomly picks a symbol for each slot. After the spin, the code checks if all three symbols match or if there’s another winning pattern I specified. The Player has a balance of $100 to start with, once the hit $0 then it's gameover. The process repeats every time you press spin.
